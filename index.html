PANDUAN KOTA OPEN WORLD

• Eksplorasi Bebas: Kamu bebas berjalan kaki atau menyetir ke mana saja di jalanan kota.
• Kamera Bebas: Tarik/usap layar di area kosong untuk melihat sekeliling 360°.
• Summon Kendaraan: Panggil motor, mobil, atau truk kapan saja melalui tab 'Summon Kendaraan'.
• Misi Pengiriman: Ambil order paket di tab 'Papan Misi' untuk menambah saldo uang.
• Keyboard PC: WASD / Panah untuk gerak, E untuk masuk/keluar, R untuk reset mobil, P untuk buka HP.
